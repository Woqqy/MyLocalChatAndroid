# My Local Chat — Android

Android-приложение на базе исходного My Local Chat. Сервер запускается внутри приложения на телефоне и доступен в локальной Wi-Fi сети на порту 8765. Данные хранятся в SQLite. Веб-интерфейс открыт внутри WebView. Чтобы другие устройства подключились, откройте на них браузер и введите `http://IP_ТЕЛЕФОНА:8765` (IP телефона смотрите в настройках Wi-Fi). Пока приложение закрыто или Android остановил его в фоне, сервер недоступен.

## Сборка APK
Откройте проект в Android Studio и выполните Build → Build APK(s), либо загрузите проект в GitHub и запустите Actions → Build APK. Готовый APK появится в Artifacts.

## Сеть
В текущей версии сервер слушает только localhost внутри приложения. Это автономный личный чат на одном телефоне; чтобы общаться с другими телефонами по Wi-Fi, понадобится включить LAN-режим сервера и выдать разрешение на работу в локальной сети.
